使用说明 / 常见问题

1. 两个模式：首页先选「单机听歌」或「一起听歌」。单机听歌自己听，不联网；一起听歌再创建房间或输入房间号，一个房间最多 3 人。点左上角「‹ 首页」随时切回来。

2. 房间号 / 大厅：房主创建后得到 6 位房间号，也可以用「复制邀请链接」「二维码」邀请；不想输号就点「看看有哪些房间」，有人在线就会出现在列表里，点「加入」直接进。人满了（3 人）房间就不再出现在列表里，第 4 个人会被直接拒。

3. 单机听歌：分「全部音乐 / 我的歌单 / ★ 收藏 / 最近」。全部音乐里点歌就播，并按当前列表自动连播；点行尾的 ＋ 把歌加进自建歌单；「我的歌单」里可以新建、重命名、删除、加歌、移出。

4. 播放模式：▶ 下面有 🔀 随机、🔁 循环（顺序 → 列表循环 → 单曲循环），切换后房间里所有人同步。

5. 控制：房间里人人权力一样，谁都能播放、暂停、拖动、切歌、加歌。安卓 App 还能在锁屏/通知栏控制播放，拔掉耳机会自动暂停。播放页支持手势：双击左侧/右侧切歌、上下滑调音量、长按封面 2× 试听；右下角可以选 0.5–2× 倍速，倍速会同步给房间里所有人。点封面进入全屏播放页，背景颜色会跟着封面变。

6. 歌词与封面：点「找歌词」打开搜索面板，一次查 LRCLIB / lyrics.ovh / Lyrist 三个源，可以填「歌手」过滤同名版本；点结果里任意一条即可套用，「自动选最佳」会直接挑最合适的。歌单里两个按钮：「整单找歌词」只补歌词，「整单补全歌词+封面」两样一起补，进度会显示在按钮下方，再点一次可中途停止。只有纯文本歌词时会先展示、但不滚动。歌词和声音对不上时，点「校准」拖滑块边听边调（只影响自己这边，不会改动对方播放），也可以「以当前句校准」一键对齐；找不到歌词可点「加歌词」手动选 .lrc 文件。播放时会自动联网匹配专辑封面，显示在播放器背景和歌单里；点封面进入全屏页，右上角「换封面」可以手动换一张图。封面会存在本地，之后断网也能显示。

7. 聊天：抽屉里切到「聊天」，发的消息其他人立刻能看到，带头像。可以点「🖼 发图片」直接发压缩后的小图、点任意消息引用回复、点表情飘屏；自己发的消息下面会显示「送达 / 已读」，2 分钟内长按自己的消息可以撤回。下面两个开关分别控制新消息的震动和提示音。聊天记录只存在本机，下次打开还在（最多 80 条，图片最多 8 张）。

8. 歌单与传输：我的歌曲是长期保存的本地列表（自己加的歌、别人传过来的歌都在这里，下次打开还在）；一起听是本次房间的共享歌单，每次进房间从空开始。在「我的歌曲」里点 ＋ 把歌加进「一起听」，所有人按添加顺序看到同一份歌单，并自动互相传文件。中途进来的人只下「当前这首歌 + 下一首」，下完自动对齐、开始播放，不会打断正在放的人；播放过程中会提前把下一首缓冲好（下一首旁边会显示「已缓冲」，单机播放同样生效，引用模式的歌会先把文件读好）。连接断了会自己一直重连（间隔越来越长），换网 / 锁屏回来也会立刻自检；顶栏小圆点会显示「中转已连 / 已连接 / 重试第几次」。实在卡住就点右上角 ↻。

9. 房主：房主可以先建房、先放歌，别人进来不影响他。房主退出后，房间里来得最早的人自动接任房主，房间照常继续。

10. 个人资料：首页右上角点自己的头像/名字，可以选内置头像、从相册选图、改用户名；进入「一起听」后所有人的顶栏和聊天都会显示头像和名字，不需要密码。

11. 限制：音量各自独立；聊天记录只保存在本机；收藏、「最近播放」和自建歌单只在自己这边生效。

12. 外观自定义：设置里点「外观自定义」，可以调全局字号（小/标准/大/特大）、强调色（含自定义取色）、歌单列表密度、播放器封面形状（方形/圆角/圆形/唱片）；还能设定「几点到几点用深色」自动切换，以及长按/切歌/按钮操作的触感反馈开关。主界面新增快捷入口栏，可勾选显示哪些按钮、用 ↑ ↓ 调整顺序。所有设置只保存在本机。

13. 性能与平台：设置页新增「存储用量」，分别显示设置与歌单、浏览器存储、音频副本、封面缓存、接收缓存的占用，可一键清理封面和接收缓存（不会删你的歌曲文件）。几百上千首的超长歌单改用虚拟滚动，只渲染当前看得见的部分，滚动更顺、不再卡顿。启动时先显示骨架屏，歌单在后台异步恢复，打开更快。网络变差（延迟高或 2G）时，播放页会出现提示，并自动降低封面和歌词的加载频率，网络恢复后自动恢复。浏览器的锁屏 / 通知栏会显示歌名、歌手、封面和播放进度，并支持快退 / 快进 10 秒。

14. 记录与分享：一起听时顶栏会显示本次已一起听的时长，点它或成员行可以看到「本次 / 累计 / 连续天数 / 一起听次数」，听满 1 小时、10 小时、100 小时或连续 3 / 7 / 30 天会点亮对应徽章（只记在本机）。传歌时点「队列」可以看到每首歌的发送、接收和续传进度，断线重连会从断点接着传，失败的歌可以点「重试」。播放队列里点「分享卡片」会生成一张歌单图片，可保存或调用系统分享发给朋友。

15. 歌单工具与数据：「我的歌单」底部可以导出歌单（一个 JSON，含歌单名、简介、封面和歌名）、导入歌单（按歌名匹配曲库，同名歌单会合并），还能用歌单模板按「通勤 / 深夜 / 学习 / 聚会」从曲库自动配一份歌单。设置页新增「数据备份」：可以备份设置、歌单、聊天和一起听统计到文件，也能从备份恢复；最下面的「清空全部数据」会删掉曲库、歌单、聊天和缓存（手机里原来的音乐文件不会被删）。长歌单的封面改成滚到哪加载到哪，只在需要时联网取图。
